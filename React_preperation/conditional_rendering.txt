1. What is conditional rendering in React?
Conditional rendering means displaying different UI elements based on a condition.

For example, in an e-commerce application:
- If a user is logged in → show Welcome Back!
- If a user is not logged in → show Login
- If a product is available → show Add to Cart
- If a product is unavailable → show Out of Stock
React uses JavaScript conditions to decide what should be displayed.

  2. Method 1: Using if-else
Suppose we want to display a welcome message based on whether a user is logged in.


function User() {
  const isLoggedIn = true;

  if (isLoggedIn) {
    return <h2>Welcome Back!</h2>;
  } else {
    return <h2>Please Login</h2>;
  }
}

export default User;

How does it work?
1. isLoggedIn is true.
2. The if condition is satisfied.
3. React displays Welcome Back!.
If you change isLoggedIn to false, it displays Please Login.

Important interview point: You can use if-else before the return statement, but you cannot write a normal if-else statement directly inside JSX curly braces.
3. Method 2: Using the ternary operator ? :
This is one of the most common conditional rendering patterns in React interviews.

Syntax:

condition ? expressionIfTrue : expressionIfFalse

Example:

function User() {
  const isLoggedIn = false;

  return (
    <div>
      {isLoggedIn ? (
        <h2>Welcome Back!</h2>
      ) : (
        <h2>Please Login</h2>
      )}
    </div>
  );
}

export default User;

Understand the logic
{isLoggedIn ? "Welcome Back!" : "Please Login"}

- ? separates the condition from the true result.
- : separates the true result from the false result.
- {} allows the JavaScript expression inside JSX.
When isLoggedIn is false, React displays Please Login.

When should you use it? Use a ternary when you need to choose between two UI results.
4. Method 3: Using the logical AND operator &&
Use && when you want to display something only if a condition is true.

Example: Display a notification only when the user has unread messages.


function Notifications() {
  const unreadMessages = 3;

  return (
    <div>
      <h2>Dashboard</h2>

      {unreadMessages > 0 && (
        <p>You have unread messages!</p>
      )}
    </div>
  );
}

export default Notifications;

How does && work?
The expression:
{unreadMessages > 0 && <p>You have unread messages!</p>}

- If the condition is true, React displays the paragraph.
- If the condition is false, React does not render the paragraph.
There is no else part.
Important interview trap: 0 && ...
Consider this code:

function Cart() {
  const cartCount = 0;

  return (
    <div>
      {cartCount && <p>Items in cart</p>}
    </div>
  );
}

This can display 0 on the screen because JavaScript's && operator returns the first falsy operand when it encounters one.

A safer version is:

{cartCount > 0 && <p>Items in cart</p>}

This is a common React interview question.
5. Method 4: Using a variable
You can store the result of a condition in a variable and then render it.


function Product() {
  const isAvailable = true;
  let message;

  if (isAvailable) {
    message = "In Stock";
  } else {
    message = "Out of Stock";
  }

  return (
    <div>
      <h2>Laptop</h2>
      <p>{message}</p>
    </div>
  );
}

export default Product;
