1. What is a Controlled Component?
A controlled component is a form element whose value is controlled by React state.

In simple words:
- React state manages the input value.
- Whenever the user types something, the state gets updated.
- React controls what value appears inside the input field.

Example: Login Form
import { useState } from "react";

function Login() {
  const [username, setUsername] = useState("");

  return (
    <div>
      <h2>Login Form</h2>

      <input
        type="text"
        value={username}
        onChange={(e) => setUsername(e.target.value)}
        placeholder="Enter username"
      />

      <p>Username: {username}</p>
    </div>
  );
}

export default Login;

Real-world applications
Controlled components are useful when building:
- Login and registration forms.
- Search bars with live filtering.
- Form validation.
- Password strength indicators.
- Dynamic forms.
- Forms where you enable or disable buttons based on input.
For example, you can disable the login button until the user enters both username and password.

2. What is an Uncontrolled Component?
An uncontrolled component is a form element whose value is managed by the DOM itself rather than React state.

In simple words:
- The DOM manages the input value.
- React does not update state on every keystroke.
- We access the input value using useRef() when required.
example:
import { useRef } from "react";

function Login() {

  const usernameRef = useRef(null);

  function handleSubmit() {
    alert(usernameRef.current.value);
  }

  return (
    <div>
      <h2>Login Form</h2>

      <input
        type="text"
        ref={usernameRef}
        placeholder="Enter username"
      />

      <button onClick={handleSubmit}>
        Submit
      </button>
    </div>
  );
}

export default Login;

How does it work?
1. The user enters a username.
2. The browser stores the value inside the input element.
3. React doesn't manage the input value through state.
4. When the user clicks Submit, useRef() accesses the DOM element.
5. We get the entered value using usernameRef.current.value.
Important line:

const usernameRef = useRef(null);
Creates a reference to access the input DOM element.
ref={usernameRef}
Connects the reference to the input element.
usernameRef.current.value

Real-world applications
Uncontrolled components are useful for:
- Simple forms where you only need values on submission.
- File upload inputs.
- Integrating with third-party DOM-based libraries.
- Forms where you don't need to react to every keystroke.

3. Controlled vs Uncontrolled Components
This is an important comparison to remember for interviews.
Feature            	             Controlled	                               Uncontrolled
Data management	                 React state	                               DOM
Uses	                           useState()	                                 useRef()
Input value	                      value	                                   Usually defaultValue
Updates	                       State updates on change	                    DOM updates directly
Data access	                      React state	                              ref.current.value
Validation	                  Easier to perform dynamically	                 Usually performed when reading the value
Control	                            React controls input	                   DOM controls input


4. Understand the difference with a real-world example
Imagine you are building an e-commerce registration form.

Controlled approach:

When a user enters their email address:
- React immediately stores the email in state.
- React checks whether the email format is valid.
- React can display an error message immediately.
- React can disable the Register button until the input is valid.

Uncontrolled approach:

When a user enters their email address:
- The browser stores the value.
- React doesn't track every change.
- When the user clicks Register, React reads the email using a ref.


5. Interview questions
Q1. Which approach is preferred in React?

Controlled components are commonly preferred for forms because React manages the input values, making validation, conditional rendering, and dynamic updates easier.

Q2. Can we use uncontrolled components in React?

Yes. React supports uncontrolled components using refs. They are useful when we don't need to track every input change.

Q3. What is the difference between value and defaultValue?

- value: Sets the input value from React state. Used in controlled components.
- defaultValue: Sets the initial input value. After that, the DOM manages changes. Used in uncontrolled components.

Q4. Can we convert an uncontrolled component into a controlled component?

Yes. We can use useState() to manage its value and add an onChange handler.
- Validation can then happen during submission.
